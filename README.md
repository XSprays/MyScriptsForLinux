# Linux Scripts

A collection of scripts I use to make Linux easier and more convenient for myself.

These scripts were written with the help of AI. I use them to streamline common tasks, fix annoying issues, and generally make my daily Linux experience smoother.

If any of these help you too, feel free to use them.

---

## Goal

Linux is powerful, but sometimes the little things take too much time or require too many steps.  
These scripts exist to reduce friction — whether it's setting up tools, fixing common problems, or automating things I do often.
